**Description:**

The Animal Shelter Intake System is a Ruby on Rails 8 web application that is designed to help animal shelters manage animal records. Users can both add and view details. Alongside edit or get rid of animals stored.

Each animal record will have a name, species, breed, age, along with adoption status, and notes section if you wanted to describe the animal more.

The application uses RESTful routes, the MVC architecture, many ERB templates, reusable partials, Rail helping, and flash messages.

No currently known issues within the tested functionality.
